# Diario de comidas

Aplicación React + Vite para registrar comidas y consultar la evolución nutricional.

## Puesta en marcha

1. Copiá `.env.example` como `.env` y cargá las credenciales públicas de tu proyecto Supabase.
2. Ejecutá `npm install`.
3. Iniciá la app con `npm run dev`.

Generá la versión de producción con `npm run build`.

## Publicar en GitHub

`.env` está ignorado por Git. Subí `.env.example`, nunca la clave real. Si alguna clave real se hubiera publicado previamente, rotala en Supabase antes de continuar.
